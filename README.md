# Red Planet: Starship to Mars

A Fabric mod for **Minecraft Java 26.3** that adds a scientifically grounded **Mars dimension**. You don't reach it
through a portal: you ride a full-scale **Starship** from launch to landing, and fly the same sequence home.

**Status:** planning. No code yet. See [docs/HANDOFF.md](docs/HANDOFF.md) for the brief and the verified toolchain.
